Excel / Google Sheets Linking Guide

500/day entries ko Excel ya Google Sheet mein kaise jodein.

Kaise Link Karein (Step-by-Step):

Step 1: Google Drive mein nayi Sheet banayein aur Row 1 mein headers rakhein: Date, QR_ID, Bill_No, Tech_Name, Mobile, Trade, Bill_Amt, Points, Note.

Step 2: Sheet mein Extensions > Apps Script kholein, neeche diya script paste karein aur Deploy > Web app (Access: Anyone) karein.

Step 3: Excel ke liye Data Security & Backup ya neeche CSV button se CSV download karke seedha Excel/Sheets mein open karein.

Google Apps Script Code (Paste in Apps Script) 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  sheet.appendRow([
    d.scannedAt || new Date().toISOString(),
    d.qrId || "",
    d.billNo || "",
    d.techName || "",
    d.techMobile || "",
    d.trade || "",
    Number(d.billAmount || 0),
    Number(d.rewardPoints || 0),
    d.note || ""
  ]);
  return ContentService.createTextOutput('{"ok":true}')
    .setMimeType(ContentService.MimeType.JSON);
}

Data Security & Backup (500/Day Scale)

Pure saal (~182,500 records) ka backup aur safety controls.

Security & Scale Guidelines:

1. Roz 500 entries ke hisab se saal mein lagbhag 1,82,500 rows hoti hain. Har hafte/mahine CSV ya JSON backup download karke drive mein rakhein.

2. Store PIN set karne se shop staff/others unauthorized reset nahi kar payenge.

3. Sabhi inputs ko sanitize karke store kiya jata hai; hamesha HTTPS links use karein.
